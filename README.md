# AVR Workbench

Free Windows GUI for AVRDUDE 8.2.

AVR Workbench is focused on visible Flash/EEPROM buffers, practical AVR programming, Fuse/Lock work, Backup/Clone MCU workflows, HEX/RAW tools, and MCU/programmer guidance.

- 392 AVR MCU profiles
- 184 programmer entries
- Flash / EEPROM buffers
- Fuse / Lock tools
- Backup / Clone MCU
- HEX / RAW utilities
- Russian and English interface
- Portable Windows build
