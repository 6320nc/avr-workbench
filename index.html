Features

Возможности

Flash / EEPROM buffers

Open, inspect, save and compare data before programming.

Открытие, просмотр, сохранение и сравнение данных до записи в MCU.

Fuse / Lock

Configuration and protection work with MCU-specific guidance.

Работа с конфигурацией и защитой с подсказками для конкретного MCU.

Backup / Clone MCU

Back up and restore selected memory and configuration areas.

Резервное копирование и восстановление выбранных областей памяти и конфигурации.

HEX / RAW tools

Byte-level utilities and direct HEX/RAW workflows.

Байтовые инструменты и прямая работа в HEX/RAW режимах.

Programmer diagnostics

Programmer, interface and connection diagnostics for AVR work.

Диагностика программатора, интерфейса и соединения для работы с AVR.

RU / EN

Russian and English interface.

Русский и английский интерфейс.
